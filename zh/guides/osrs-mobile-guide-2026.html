① Mobile vs PC — Key Differences（手机 vs 电脑 — 关键区别）

OSRS Mobile is a fully-featured version（功能完整的版本）of the game — not a "lite" app. But there ARE important differences you should know（但确实有重要区别需注意）:

① 5 Major Differences (Mobile vs PC)（5 大区别（手机 vs 电脑））

📱 Mobile vs PC Comparison（手机 vs 电脑对比）

  • Camera:（镜头）Pinch-zoom + two-finger drag (no mouse)（双指捏合缩放 + 双指拖拽，无鼠标）
  • Menus:（菜单）Tap-hold for right-click options (takes practice!)（长按呼出右键菜单，需练习！）
  • Plugins:（插件）RuneLite plugins work on Mobile (with limiations)（RuneLite 插件在手机上可用，有限制）
  • Performance:（性能）Mobile = ~20–30 FPS (PC = 60+ FPS)（手机约 20–30 帧，电脑 60+ 帧）
  • Interface:（界面）Simplified (some PC features hidden in "More" menu)（简化，部分电脑功能藏在"更多"菜单）
💡 You Can Switch Freely Between Mobile & PC（可在手机与电脑间自由切换）

Your account is cloud-saved（云端保存）. Start a herb run on Mobile → finish on PC 10 minutes later. The game state is identical（游戏状态完全一致）across devices. This is HUGE for efficiency!

② Download & Setup Guide (iOS + Android)（下载与设置指南（iOS + 安卓））

Installation takes 2 minutes（安装约 2 分钟）. Here's the exact process for both platforms:

② iOS (iPhone/iPad) — Step-by-Step（iOS（iPhone/iPad）— 分步指南）

📱 iOS Installation（iOS 安装）

  1. Open App Store（应用商店）→ search "Old School RuneScape"（搜索"Old School RuneScape"）
  2. Tap "Get"（点击"获取"，免费下载，约 150MB）
  3. Open the app → tap "Existing User"（打开应用 → 点击"现有用户"，你已有账号）
  4. Enter your email + password（输入邮箱 + 密码，与电脑登录相同）
  5. Wait for the game to load (~30 seconds on first launch)（等待游戏加载，首次启动约 30 秒）

③ Android — Step-by-Step（安卓 — 分步指南）

🤖 Android Installation（安卓安装）

  1. Open Google Play Store（谷歌 Play 商店）→ search "Old School RuneScape"（搜索"Old School RuneScape"）
  2. Tap "Install"（点击"安装"，免费，约 150MB）
  3. Open the app → tap "Existing User"（打开应用 → 点击"现有用户"）
  4. Enter your email + password（输入邮箱 + 密码）
  5. If you have 2FA enabled（若启用两步验证，推荐！）, enter the 6-digit code from your authenticator app（输入验证器应用的 6 位验证码）

④ First Launch — Initial Setup（首次启动 — 初始设置）

⚙️ Must-Do First-Time Settings（首次必做设置）

  • Graphics quality:（画质）Set to "Medium" (High = battery drain, Low = ugly)（设为"中"：高费电，低难看）
  • Login method:（登录方式）Enable Biometric login（启用生物识别登录，FaceID/指纹）—— never type your password again!（再也不用输密码！）
  • Sound:（声音）Toggle OFF (you'll want to play quietly in public)（关闭，公共场所安静游玩）

③ Touch Controls Mastery（触控操作精通）

Mobile controls feel weird at first. Here's the complete control reference（完整操作参考）:

⑤ Basic Gestures (Master These First)（基础手势（先掌握这些））

Gesture（手势）Action（动作）When to Use（使用时机）
Tap（点按）Walk / Interact（移动 / 交互）Moving, talking to NPCs（移动、与 NPC 对话）
Tap-hold (1 sec)（长按 1 秒）Right-click menu（右键菜单）All right-click options (CRITICAL!)（所有右键选项，关键！）
Double-tap（双击）Run / Stop running（跑步 / 停止跑步）Toggle run mode（切换跑步模式）
Pinch-zoom（双指捏合）Zoom in/out（放大 / 缩小）See details / See more area（查看细节 / 看更广区域）
Two-finger drag（双指拖拽）Rotate camera（旋转镜头）Adjust viewing angle（调整视角）

⑥ Advanced Gestures (Game-Changers)（高级手势（改变体验））

🎮 Advanced Touch Techniques（高级触控技巧）

  1. Tap-hold-drop:（长按丢弃）Tap-hold item → "Drop" = fastest inventory clearing（长按物品 → "丢弃" = 最快清理背包）
  2. Two-finger tap:（双指点击）Opens minimap（打开小地图，经仙灵环等快速旅行）
  3. Swipe from left edge:（从左边缘滑动）Opens side panel（打开侧边栏：祈祷、法术、背包）
  4. Tap-hold spell → tap target:（长按法术 → 点击目标）Cast combat spells without opening spellbook（不打开魔法书也能施放战斗法术）

⑦ Customizing Your Layout (Important!)（自定义布局（重要！））

🎨 Mobile UI Customization（手机界面自定义）

  • Move action bar:（移动动作栏）Drag the bottom bar up/down for comfortable thumb reach（拖拽底部栏上下，拇指舒适触及）
  • Enable tap-to-drop:（启用点按丢弃）Settings → Gameplay → enable "Tap to drop" (faster than tap-hold)（设置 → 游戏 → 启用"点按丢弃"，比长按更快）
  • Resize spells/prayers:（调整法术/祈祷尺寸）Settings → Interface → make prayer icons BIGGER (easier to tap during combat)（设置 → 界面 → 放大祈祷图标，战斗时更易点击）
💡 Practice Tap-Hold on Chickens（在鸡身上练习长按）

Tap-hold is the most important gesture（最重要的手势）—— it replaces right-click. Go to Lumbridge → tap-hold a chicken → select "Attack" to practice. Get this muscle memory DOWN!

④ Settings You MUST Change on Mobile（手机上必改的设置）

Default settings are NOT optimized（默认设置未优化）. Change these 5 settings immediately（立即修改这 5 项）:

⑧ Essential Settings Checklist（必改设置清单）

⚙️ Setting 1: Enable "Tap to Drop"（设置 1：启用"点按丢弃"）

Path:（路径）Settings → Gameplay → "Tap to drop" = ON. Now you can drop items with a single tap (no more tap-hold → Drop!).

⚙️ Setting 2: Set Graphics to "Medium"（设置 2：画质设为"中"）

Path:（路径）Settings → Display → Graphics quality = "Medium". "High" kills your battery in 2 hours. "Low" looks terrible.

⚙️ Setting 3: Enable "Pinch to Zoom"（设置 3：启用"捏合缩放"）

Path:（路径）Settings → Gameplay → "Pinch to zoom" = ON. Essential for herb runs (need to see exact farm health)（草药日常必备，需看清农田状态）.

⚙️ Setting 4: Disable "Chat Box Transparancy"（设置 4：关闭"聊天框透明"）

Path:（路径）Settings → Interface → "Chat transparency" = OFF. On mobile, you need to SEE chat messages (quest dialog, NPC replies)（手机上需看清聊天消息：任务对话、NPC 回复）.

⚙️ Setting 5: Enable "Brightness Adjustment"（设置 5：启用"亮度调节"）

Path:（路径）Settings → Display → "Brightness" = AUTO. Playing outdoors? Auto-brightness is a must (sunlight washes out the screen)（户外游玩，自动亮度必备）.

⑨ RuneLite Mobile Plugins (Yes, They Work!)（RuneLite 手机插件（可用！））

🔌 Best Mobile Plugins（最佳手机插件）

  • Menu Entry Swapper:（菜单项交换器）Tap-hold defaults to MOST-USED option (set "Attack" as default for monsters)（长按默认最常用的选项，可为怪物设"攻击"为默认）
  • Item Identification:（物品识别）Shows exact item name when tapping items (no more guessing!)（点击物品显示准确名称，不再猜测！）
  • Bank Compact:（银行压缩）Makes your bank viewable on mobile (default bank layout = unreadable on small screens)（让银行在手机上可读，默认布局小屏难读）

⑤ What Works BEST on Mobile（手机上最擅长的内容）

Not all activities are mobile-friendly. Here's the definitive ranking（明确分级）:

⑩ S-Tier (Perfect for Mobile)（S 级（非常适合手机））

✅ DO These on Mobile（在手机上做这些）

  • Herb runs:（草药日常）Tap-hold herbs → pick. 5-minute activity = perfect for mobile（长按草药 → 采集，5 分钟活动，手机完美）
  • farming patches (non-herb):（农田（非草药））Tree runs, fruit tree runs, bush runs = all mobile-friendly（树种、果树、灌木日常，皆适合手机）
  • Grand Exchange:（大交易所）Buy/sell items while on the bus/metro（公交/地铁上买卖物品）
  • Quest dialog:（任务对话）Long quest conversations = read on mobile while doing other things（长篇任务对话，边做别的事边在手机上看）
  • Skill training (passive):（技能训练（被动））Fishing, Woodcutting, Mining = tap once, wait 20 seconds（钓鱼、伐木、采矿，点一次等 20 秒）

⑪ A-Tier (Good on Mobile)（A 级（手机上不错））

✅ These Are Also Fine（这些也不错）

  • Slayer tasks (easy):（屠戮任务（简单））Killing cows, chickens, low-level monsters（杀牛、鸡、低级怪物）
  • Clue Scrolls (easy):（线索卷轴（简单））Easy clue scrolls = tap-around, no combat pressure（简单线索，点按即可，无战斗压力）
  • Agility courses (low-level):（敏捷课程（低级））Gnome Stronghold course = simple taps in order（侏儒据点课程，按顺序简单点按）

⑫ B-Tier (Okay, but not ideal)（B 级（还行，但不理想））

⚠️ Do These If You Must（必须时再做这些）

  • Bossing (low-level):（打 Boss（低级））Obor, Barrows = possible but clunky (Prayer switching is HARD on mobile)（奥伯、阿巴罗，可行但笨拙，手机上切换祈祷很难）
  • Agility (high-level):（敏捷（高级））High-level courses need precise timing = frustrating on touchscreen（高级课程需精准 timing，触屏令人挫败）

⑥ What to AVOID on Mobile (Don't Do These!)（手机上应避免的内容（千万别做！））

Some content is genuinely dangerous（确实危险）on mobile. Avoid these:

⑬ NEVER Do These on Mobile（手机上绝对别做这些）

❌ #1: High-Level PvP (Wilderness)（高级 PvP（荒野））

Wilderness PvP needs split-second Prayer switching（分秒级祈祷切换）. On mobile, your tap-hold → Prayer switch takes 2-3 seconds. You'll die instantly to a PC player.

❌ #2: High-Level Raids (CoX, ToB)（高级突袭（CoX、ToB））

These need voice call coordination（语音协调）+ precise clicking. Mobile interface can't handle the mechanic complexity. You'll wipe your raid team.

❌ #3: Inferno / Fight Caves（炼狱 / 战斗洞窟）

These need pixel-perfect prayer switching（像素级祈祷切换）+ precise movement. Even PC players struggle. On mobile = 0% success rate.

❌ #4: items over 10M GP in Wilderness（荒野中携带价值超 10M GP 的物品）

Even if you're just doing herb runs in low Wilderness — if you die to a PKer, you lose EVERYTHING（失去一切）. Mobile = slow reaction time = easy PK kill.

💡 Safe Mobile Play = Stay in P2P Zones（安全手机游玩 = 留在 P2P 区域）

NEVER go to Wilderness on mobile with valuable items. Even "just for a quick herb run" = you WILL get PKed. Stick to safe zones (all P2P areas except Wilderness)（留在安全区：除荒野外所有 P2P 区域）.

⑦ Battery & Data Saving Tips（省电与省流量技巧）

OSRS Mobile CAN drain your battery fast. Here's how to make it last 8+ hours（撑 8 小时以上）:

⑭ Battery Saving Settings（省电设置）

🔋 5 Battery Tips（5 个省电技巧）

  1. Graphics = Medium (NOT High):（画质 = 中，非高）Saves ~40% battery（省约 40% 电量）
  2. Screen brightness = 50%:（屏幕亮度 = 50%）Auto-brightness OFF, manual = 50%（关闭自动亮度，手动 50%）
  3. Disable "Dynamic Shadows":（关闭"动态阴影"）Settings → Display → Shadows = OFF（设置 → 显示 → 阴影 = 关）
  4. Use "Battery Saver" mode on your phone:（开启手机"省电模式"）iOS Low Power Mode / Android Battery Saver（iOS 低电量模式 / 安卓省电模式）
  5. Close other apps:（关闭其他应用）OSRS Mobile needs ALL available RAM (especially on 4GB RAM phones)（手机版需要全部可用内存，尤其 4GB 内存手机））

⑮ Data Usage (Mobile Network vs WiFi)（流量使用（移动网络 vs WiFi））

📡 Data Consumption（流量消耗）

OSRS Mobile uses ~30-50MB per hour（每小时约 30–50MB，出奇地低！）. But:

  • WiFi = ALWAYS prefer:（WiFi = 始终优先）Home WiFi / coffee shop WiFi = free and stable（家用 / 咖啡店 WiFi，免费稳定）
  • Mobile data = use for short sessions:（移动数据 = 仅短时使用）Herb runs (5 min) = ~5MB data. Totally fine.（草药日常 5 分钟约 5MB，完全没问题。）
  • AVOID:（避免）Long AFK sessions (8+ hours) on mobile data = ~400MB (not huge, but why waste it?)（移动数据长时间挂机 8+ 小时约 400MB，不多但何必浪费？）

⑯ Offline Mode (Can You Play Without Internet?)（离线模式（无网络能玩吗？））

📶 Can OSRS Mobile Play Offline?（OSRS 手机版能离线玩吗？）

NO.（不能。）OSRS is an MMO — it requires constant internet. But you CAN play on very slow connections（但可在极慢连接下游玩，3G 也能用！）(even 3G works!). Just don't expect to play on an airplane (no WiFi = no game).

⑧ Mobile FAQ — Common Questions（手机常见问题）

Can I use a mouse/keyboard with OSRS Mobile?（手机版能用鼠标/键盘吗？）

iOS:（iOS）No (unless you jailbreak, which is against OSRS rules)（不能，越狱违反 OSRS 规则）.
Android:（安卓）Yes! Some Android phones support mouse/keyboard via USB-OTG（部分安卓支持 USB-OTG 鼠标/键盘）. But this is "mobile" in name only — you're basically playing PC version at that point.

My phone overheats while playing. What do I do?（游玩时手机过热怎么办？）

Cause:（原因）"High" graphics settings + no ventilation（高画质 + 无通风）.
Fix:（解决）Set graphics to "Medium" + remove phone case + play on a tablet（平板散热更好）instead. Never play while charging（绝不在充电时游玩）—— that's instant overheat.

Can I trade with other players on mobile?（手机上能与其他玩家交易吗？）

Yes!（能！）Trading works perfectly on mobile. Tap-hold player → "Trade with" → confirm trade. The trade interface is actually easier（交易界面其实更简单）on mobile (bigger buttons!).

Is RuneLite available on iOS?（iOS 上能用 RuneLite 吗？）

NO.（不能。）RuneLite is Android-only（仅安卓，需侧载）(requires sideloading). iOS users can't use RuneLite plugins. But the official mobile app（官方手机应用）has built-in plugins (Menu Entry Swapper, etc.) that cover 70% of RuneLite features.

Can I do Barrows on mobile?（手机上能打阿巴罗（Barrows）吗？）

Yes, but it's clunky.（能，但笨拙。）Barrows needs Prayer switching (Protect from Melee/Magic/Ranged). On mobile, opening the Prayer tab + tapping the right prayer takes 3-4 seconds. You'll take damage. Doable, but NOT optimal. Wait until you're at a PC for Barrows.
