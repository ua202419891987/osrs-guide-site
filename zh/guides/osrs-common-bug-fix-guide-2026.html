1. Jagex Launcher Black Screen（Jagex 启动器黑屏）

黑屏是 Jagex 启动器被报告最多的问题。启动器能打开，但只显示黑色窗口。这通常是由缓存损坏、显示驱动冲突或硬件加速问题引起的。请按顺序尝试以下修复：The black screen issue is the most-reported problem with the Jagex Launcher. The launcher opens but shows only a black window. This is caused by cache corruption, display driver conflicts, or hardware acceleration issues.

① Fix 1: Clear Jagex Launcher Cache（清除启动器缓存）

Windows 步骤

  1. 彻底关闭 Jagex 启动器（检查系统托盘确认完全退出）
  2. 按 Win + R，输入 %localappdata%\Jagex Launcher 并回车
  3. 打开 cache 文件夹，删除里面所有内容
  4. 重新启动 Jagex 启动器

② Fix 2: Run as Administrator（以管理员身份运行）

  1. 右键 Jagex 启动器快捷方式
  2. 选择 属性 → 兼容性 选项卡
  3. 勾选 "以管理员身份运行此程序"
  4. 点击应用并确定，然后重新启动

③ Fix 3: Reset Internet Settings（重置 Internet 设置）

Jagex 启动器依赖内置浏览器组件。重置 Internet 设置可修复渲染问题：The Jagex Launcher relies on embedded browser components. Resetting Internet settings can fix rendering issues:

  1. 打开 控制面板 → 网络和 Internet → Internet 选项
  2. 切换到 高级 选项卡
  3. 点击 "重置 Internet Explorer 设置" 下的 重置
  4. 勾选 "删除个人设置" 并点击重置
  5. 重新启动 Jagex 启动器

④ Fix 4: Update Your Graphics Driver（更新显卡驱动）

过时的显卡驱动是启动器渲染问题的常见原因：Outdated graphics drivers are a common cause of rendering issues in the launcher:

  • NVIDIA：下载 GeForce Experience 或访问 nvidia.com/drivers
  • AMD：访问 amd.com/support 获取最新 Adrenalin 驱动
  • Intel：访问 intel.com/support 获取核显驱动

💡 Quick Test: Use the Official Client Instead（快速测试：改用官方客户端）

如果以上方法都无效，尝试通过官方 Old School RuneScape 客户端（不是 Jagex 启动器）启动 OSRS。如果官方客户端能用而启动器不行，问题就出在启动器本身——带上你的系统配置和问题描述向 Jagex 提交工单。If none of the above fixes work, try launching OSRS through the official Old School RuneScape client. If the official client works but the launcher doesn't, submit a support ticket to Jagex with your system specs.

2. Game Crashing / Crashes on Startup（游戏崩溃 / 启动崩溃）

如果游戏在加载时、登录后不久或游玩中随机崩溃，原因通常是驱动冲突、Java 问题或缓存损坏。If the game crashes during loading, shortly after login, or randomly during play, the cause is usually a driver conflict, Java issue, or corrupted cache.

⑤ Fix 1: Update GPU Drivers (Recommended)（更新显卡驱动，推荐）

这是游戏崩溃最常见的原因。请使用干净安装方式：This is the most common cause of game crashes. Use a clean driver installation:

  1. 从 guru3d.com 下载 Display Driver Uninstaller (DDU)
  2. 以 安全模式 启动 Windows
  3. 运行 DDU 彻底移除当前显卡驱动
  4. 回到正常 Windows，从 NVIDIA/AMD/Intel 安装最新驱动

⑥ Fix 2: Disable Third-Party Overlays（关闭第三方叠加层）

Discord、Xbox Game Bar、Steam 或 NVIDIA GeForce Experience 的叠加层可能与 OSRS 冲突：Overlays from Discord, Xbox Game Bar, Steam, or NVIDIA GeForce Experience can conflict with OSRS:

  • Discord：设置 → 游戏叠加层 → 关闭游戏内叠加层
  • Xbox Game Bar：设置 → 游戏 → 游戏栏 → 关
  • NVIDIA：GeForce Experience → 设置 → 通用 → 游戏内叠加层 → 关
  • Steam：设置 → 游戏内 → 关闭 Steam 叠加层

⑦ Fix 3: Increase Virtual Memory（增加虚拟内存）

如果系统内存不足，OSRS 会毫无预警地崩溃：If your system runs low on memory, OSRS can crash without warning:

  1. 右键 此电脑 → 属性
  2. 点击 高级系统设置 → 性能设置
  3. 切换到 高级 选项卡 → 虚拟内存 → 更改
  4. 取消勾选 "自动管理分页文件大小"
  5. 将 初始大小 和 最大值 设为 内存的 1.5 倍（例如 16GB 内存 = 24576 MB）
  6. 点击设置、确定并重启电脑

⑧ Fix 4: Clear the Game Cache（清除游戏缓存）

官方客户端：按 Win + R，输入 %userprofile%\jagexcache\oldschool\LIVE 删除全部内容，重启游戏会重新生成缓存。For the official client: Press Win + R, type %userprofile%\jagexcache\oldschool\LIVE and delete all contents. Restart the game — it will regenerate the cache fresh.

RuneLite：打开 RuneLite 启动器 → 点击 齿轮图标 → 清除缓存 → 重新启动。For RuneLite: Open RuneLite launcher → click the gear icon → Clear cache → Relaunch.

3. RuneLite Not Loading or Crashing（RuneLite 无法加载或崩溃）

RuneLite 是最受欢迎的第三方 OSRS 客户端，但它也有自己的一套常见问题。RuneLite is the most popular third-party OSRS client, but it has its own set of common issues.

⑨ Fix 1: Clear RuneLite Configuration（清除 RuneLite 配置）

损坏的插件设置是 RuneLite 问题的常见原因：Corrupted plugin settings are a common cause of RuneLite issues:

  1. 彻底关闭 RuneLite
  2. 按 Win + R，输入 %userprofile%\.runelite 并回车
  3. 删除整个 .runelite 文件夹（这会重置所有插件和设置）
  4. 启动 RuneLite——它会用默认设置重新生成文件夹

注意：这会重置你所有的插件配置、瓦片标记和自定义设置。如果想保留设置，只删除 .runelite 里的 cache 文件夹即可。This will reset ALL your plugin configurations, tile markers, and custom settings. To preserve your settings, only delete the cache folder inside .runelite instead.

⑩ Fix 2: Check Java Version（检查 Java 版本）

RuneLite 需要 Java 8 或 11（64 位）。如果装了多个 Java 版本，可能会冲突：RuneLite requires Java 8 or 11 (64-bit). If you have multiple Java versions installed, conflicts can occur:

  1. 按 Win + R，输入 cmd 并回车
  2. 输入 java -version 查看输出
  3. 如果 Java 不是 8 或 11（64 位），从 java.com 下载 Java 8
  4. 从控制面板 → 程序和功能卸载其他 Java 版本

⑪ Fix 3: Run RuneLite as Administrator（以管理员运行 RuneLite）

  1. 右键 RuneLite.exe（或快捷方式）
  2. 选择 属性 → 兼容性 选项卡
  3. 勾选 "以管理员身份运行此程序"
  4. 如果上面无效，再勾选 "以兼容模式运行（Windows 8）"
  5. 应用并重新启动

⑫ Fix 4: Disable Problematic Plugins（禁用有问题的插件）

如果 RuneLite 能启动但一登录或进入某些区域就崩溃，可能是插件导致的：If RuneLite launches but crashes when you log in or enter certain areas, a plugin might be the cause:

  1. 按住 Shift 启动 RuneLite（进入安全模式）
  2. 如果安全模式正常，逐个重新启用插件直到找到罪魁祸首
  3. 常见有问题的插件：GPU、HDOS、117 HD、Animation Smoothing

💡 RuneLite Safe Mode Shortcut（RuneLite 安全模式快捷键）

如果 RuneLite 一启动就崩溃，双击图标时按住 Shift 键。这会在禁用所有插件的安全模式下打开启动器，让你无需崩溃就能修复配置问题。If RuneLite crashes immediately on launch, hold the Shift key while double-clicking the RuneLite icon.

4. Login Issues & Connection Problems（登录问题与连接故障）

"Still waiting for game response..."（仍在等待游戏响应）和 "Login server disconnected"（登录服务器已断开）是每个 OSRS 玩家都熟悉的提示。以下是经过验证的修复方法："Still waiting for game response..." and "Login server disconnected" are familiar messages to every OSRS player.

⑬ Fix 1: Switch Worlds（切换世界）

最简单的修复。在登录界面点击 切换世界 选择不同服务器。总等级世界（标记为 "2,000 Total" 等数字）通常玩家更少、连接更好。On the login screen, click Switch World and choose a different server. Total-level worlds often have fewer players and better connectivity.

⑭ Fix 2: Flush DNS Cache（刷新 DNS 缓存）

  1. 以管理员身份打开 命令提示符（按 Win + X → 命令提示符(管理员) 或终端(管理员)）
  2. 输入 ipconfig /flushdns 并回车
  3. 依次输入 ipconfig /release 然后 ipconfig /renew
  4. 关闭命令提示符并重启 OSRS

⑮ Fix 3: Change DNS Server（更改 DNS 服务器）

你的 ISP 的 DNS 可能很慢或不稳定。切换到公共 DNS 提供商：Your ISP's DNS can be slow or unreliable. Switch to a public DNS provider:

  1. 打开 控制面板 → 网络和共享中心 → 更改适配器设置
  2. 右键你的连接 → 属性
  3. 选择 Internet 协议版本 4 (TCP/IPv4) → 属性
  4. 选择 "使用以下 DNS 服务器地址"
  5. 首选填 8.8.8.8、备用填 8.8.4.4（Google DNS）
  6. 或填 1.1.1.1 和 1.0.0.1（Cloudflare DNS）
  7. 点击确定并重启电脑

⑯ Fix 4: Disable VPN / Proxy（关闭 VPN / 代理）

虽然 VPN 在某些情况下能改善路由，但它也可能触发 Jagex 的反作弊系统导致登录失败。排查时请临时关闭任何 VPN、代理或网络加速器：While a VPN can help with routing issues in some cases, it can also trigger Jagex's anti-cheat systems causing login failures.

  • VPN：断开连接后再试
  • Kill Switch / 分流隧道：确保 OSRS 流量没有经过 VPN
  • 代理设置：Windows 设置 → 网络与 Internet → 代理 → 关闭 "使用代理服务器"

💡 Check Server Status First（先检查服务器状态）

在做任何复杂排查之前，先访问 OSRS 服务器状态页（oldschool.runescape.com）或 Jagex 支持页（support.runescape.com）确认服务器在线。有时问题出在 Jagex 那边，本地再怎么排查也没用——只能等。Before doing any complex troubleshooting, check the OSRS server status page to confirm the servers are online.

5. High Ping / Lag / Frequent Disconnects（高延迟 / 卡顿 / 频繁掉线）

如果你的游戏卡顿或频繁断开，问题可能出在网络连接或特定的游戏世界上。If your game is lagging or disconnecting regularly, the issue is likely with your network connection or the specific game world.

⑰ Fix 1: Use Wired Connection（使用有线连接）

Wi-Fi 虽然方便，但会引入延迟和丢包。要获得最稳定的 OSRS 体验，请用 以太网线直连路由器。Wi-Fi is convenient but introduces latency and packet loss. For the most stable OSRS experience, use an Ethernet cable directly to your router.

⑱ Fix 2: Choose the Right World for Your Region（为你的地区选对世界）

你的地区最佳世界类型说明

北美（西部）美西世界（321-340）美西/加拿大最佳
英国 / 欧洲英国世界（341-370）欧洲玩家延迟最佳

⑲ Fix 3: Add OSRS to Firewall Exceptions（将 OSRS 加入防火墙例外）

防火墙或杀毒软件可能拦截 OSRS 连接：Firewall or antivirus software can block OSRS connections:

  1. 打开 Windows 安全中心 → 防火墙和网络保护
  2. 点击 "允许应用通过防火墙"
  3. 点击 "更改设置" 然后 "允许其他应用"
  4. 浏览并添加：RuneLite.exe、JagexLauncher.exe、RS2Client.exe
  5. 确保每一项都勾选 专用 和 公用

⑳ Fix 4: Restart Your Router（重启路由器）

有时最简单的修复最有效。拔掉路由器电源 30 秒，重新插上，等它完全重启（所有指示灯稳定）后再试。Unplug your router for 30 seconds, plug it back in, wait for it to fully restart, and try again.

6. Graphics Issues: Stuttering, Tearing, Blurry（画面问题：卡顿、撕裂、模糊）

OSRS 的渲染器可能导致各种显示问题。以下是修复方法：OSRS's renderer can cause various display issues.

⑴ Fix 1: Enable the GPU Plugin (RuneLite)（启用 GPU 插件）

RuneLite 的 GPU 插件能大幅提升性能和画质：RuneLite's GPU plugin dramatically improves performance and visual quality:

  1. 打开 RuneLite → 插件侧栏 → 搜索 "GPU"
  2. 启用 GPU 插件
  3. 将 渲染距离 设为 25-50（越高可见范围越大但 GPU 负担越重）
  4. 将 FPS 目标 设为显示器刷新率（60、144 等）
  5. 如果输入有延迟，关闭 VSync

⑵ Fix 2: Disable VSync（关闭垂直同步）

VSync 会导致 OSRS 鼠标输入延迟。在 RuneLite 的 GPU 插件设置里关闭它。如果想防止画面撕裂，改用显卡控制面板的 Fast Sync（NVIDIA）或 Enhanced Sync（AMD）。VSync can cause mouse input lag in OSRS. Disable it in RuneLite's GPU plugin settings.

⑶ Fix 3: Adjust Windows Display Settings（调整 Windows 显示设置）

  • 修复模糊文字：设置 → 显示 → 缩放与布局 → 设为 100%（推荐）
  • 修复卡顿：设置 → 游戏 → 游戏模式 → 关
  • 修复撕裂：设置 → 显示 → 高级显示 → 为 OSRS 选较低分辨率（如 1280x720）

⑷ Fix 4: Check Monitor Connection（检查显示器连接）

如果你用的是高刷新率显示器（144Hz+），确保使用 DisplayPort 或 HDMI 2.0+。旧接口如 VGA 或 DVI 无法支持高刷新率，可能导致显示问题。If you have a high-refresh-rate monitor (144Hz+), make sure you're using DisplayPort or HDMI 2.0+.

7. Jagex Launcher Won't Update（Jagex 启动器无法更新）

当 Jagex 启动器卡在 "Checking for updates"（正在检查更新）或无法下载更新时：When the Jagex Launcher gets stuck on "Checking for updates" or fails to download updates:

⑸ Fix 1: Clean Reinstall（干净重装）

  1. 从 控制面板 → 程序和功能 卸载 Jagex 启动器
  2. 删除残留文件夹：%localappdata%\Jagex Launcher 和 C:\Program Files (x86)\Jagex Launcher
  3. 从 oldschool.runescape.com 下载最新安装包
  4. 安装并启动

⑹ Fix 2: Check Antivirus（检查杀毒软件）

Avast、McAfee 或 Bitdefender 等杀毒软件可能拦截启动器更新。临时关闭杀毒软件，启动 Jagex 启动器让它更新，然后再重新启用。或者把整个 Jagex 启动器文件夹加入杀毒软件白名单。Antivirus programs may block the launcher update process. Temporarily disable your antivirus, launch the Jagex Launcher, let it update, then re-enable your antivirus.

⑺ Fix 3: Check Disk Space（检查磁盘空间）

Jagex 启动器至少需要系统盘（通常是 C:）有 500 MB 空闲空间来下载和应用更新。在文件资源管理器 → 此电脑里查看可用空间。The Jagex Launcher needs at least 500 MB of free space on your system drive to download and apply updates.

8. General Troubleshooting Checklist（通用故障排查清单）

当你遇到任何 OSRS 技术问题时，先过一遍这份清单：When you encounter any OSRS technical issue, run through this checklist first:

🔧 Universal Troubleshooting Order（通用排查顺序）

  1. 重启一切：关闭 OSRS、关闭启动器、重启电脑
  2. 检查服务器状态：访问 oldschool.runescape.com 看服务器是否在线
  3. 清除启动器缓存：%localappdata%\Jagex Launcher\cache — 删除里面所有内容
  4. 更新显卡驱动：从 NVIDIA/AMD/Intel 下载最新驱动
  5. 以管理员运行：Jagex 启动器、RuneLite 和游戏客户端
  6. 关闭叠加层：Discord、Xbox Game Bar、NVIDIA 叠加层、Steam 叠加层
  7. 刷新 DNS：命令提示符(管理员) 里 ipconfig /flushdns
  8. 更改 DNS：8.8.8.8 / 8.8.4.4（Google）或 1.1.1.1 / 1.0.0.1（Cloudflare）
  9. 重装：卸载并重装客户端（不留任何东西——删除残留文件夹）
  10. 提交工单：如果都不行，访问 support.runescape.com

9. Bug Fix FAQs（常见问题）

Why does my Jagex Launcher show a black screen?（启动器为什么黑屏？）

这是由缓存损坏或显示渲染问题引起的。清除缓存（%localappdata%\Jagex Launcher\cache）、以管理员运行启动器、并更新显卡驱动。如果问题持续，尝试通过控制面板 → Internet 选项 → 高级 → 重置来重置 Internet 设置。

RuneLite keeps crashing when I log in. What's wrong?（RuneLite 一登录就崩溃，怎么回事？）

很可能是某个插件导致的崩溃。启动 RuneLite 时按住 Shift 进入安全模式（禁用所有插件）。如果能正常启动，逐个启用插件直到找到问题。常见元凶包括 GPU 插件、117 HD、HDOS 和 Animation Smoothing。

I keep getting "Login server disconnected." How do I fix this?（一直提示登录服务器断开，怎么修？）

按顺序尝试：(1) 切换到不同世界，(2) 刷新 DNS（管理员 CMD 里 ipconfig /flushdns），(3) 把 DNS 改成 8.8.8.8（Google）或 1.1.1.1（Cloudflare），(4) 关闭任何 VPN 或代理，(5) 把 OSRS 加入防火墙例外。

OSRS crashes without any error message. What do I do?（OSRS 无任何报错就崩溃，怎么办？）

这通常是由旧显卡驱动或内存问题引起的。用 DDU（Display Driver Uninstaller）干净安装最新 GPU 驱动，然后把虚拟内存增加到内存的 1.5 倍。关闭 Discord 叠加层和 Xbox Game Bar，它们可能导致静默崩溃。

My game is laggy even though I have a good PC. How do I fix this?（电脑配置很好但游戏还是卡，怎么修？）

如果还没启用 RuneLite 的 GPU 插件，先启用它，把渲染距离设为 25-50。在 RuneLite 设置里关闭 VSync。确保你用的是所在地区正确的世界。关闭可能占用带宽或 GPU 资源的浏览器标签页和其他程序。

Should I use the official client or RuneLite?（该用官方客户端还是 RuneLite？）

RuneLite 是 Jagex 官方认可的，并提供大量生活质量改进（任务助手、GPU 渲染、经验追踪、瓦片标记）。官方客户端更稳定但功能较少。大多数老玩家用 RuneLite。如果 RuneLite 出问题，用官方客户端测试一下，判断问题是否 RuneLite 专属。

I can't log in after upgrading to a Jagex account. What happened?（升级成 Jagex 账号后无法登录，怎么了？）

如果你升级到了 Jagex 账号，必须用 Jagex 启动器登录。旧的官方客户端和直接用户名/密码登录已不再可用。从 oldschool.runescape.com 下载 Jagex 启动器，安装后用新的 Jagex 账号凭据登录。

How do I submit a bug report to Jagex?（怎么向 Jagex 提交 bug 报告？）

访问 support.runescape.com 选择对应的问题分类。技术问题请附上：(1) 系统配置（CPU、GPU、内存、系统版本），(2) 详细的问题描述及发生时机，(3) 任何报错信息或截图，(4) 你已经尝试过的步骤。通过支持文章底部的 "Contact Us" 表单提交。

My RuneLite plugins reset after every update. Can I prevent this?（RuneLite 插件每次更新后都重置，能避免吗？）

这通常发生在 .runelite 文件夹被删除或损坏时。把整个 %userprofile%\.runelite 文件夹复制到一个安全位置做备份。另一个原因是用管理员身份运行 RuneLite——这会改变设置保存的位置。尽可能用普通身份运行 RuneLite（不用管理员）。

Is there a way to fix OSRS issues without reinstalling?（有没有不用重装就能修 OSRS 问题的方法？）

有。从最简单的修复开始：重启电脑、清除启动器缓存、更新显卡驱动、以管理员运行客户端。这些能不重装就解决 90% 的问题。只有通用排查清单（第 8 节）完全失效时才重装。

🎯 Quick Troubleshooting Flowchart（快速排查流程图）

遇到技术问题时用这个决策树：Use this decision tree when you hit a technical issue:

❓ 启动器打不开 / 黑屏？ → 清缓存 → 管理员运行 → 重置 Internet 设置 → 重装
❓ 启动就崩溃？ → 更新 GPU 驱动 → 关叠加层 → 加虚拟内存 → RuneLite 安全模式
❓ 无法登录 / 断线？ → 查服务器状态 → 换世界 → 刷 DNS → 改 DNS → 关 VPN
❓ 卡顿 / 高延迟？ → 用有线连接 → 选地区世界 → 防火墙例外 → 重启路由器
❓ 画面问题？ → 启用 GPU 插件(RuneLite) → 关 VSync → 调显示设置 → 查显示器线

Still stuck?（还是卡住？） 访问 Jagex 支持网站（support.runescape.com）或在 OSRS 社区 Discord 服务器求助。社区几乎修过所有问题——有人经历过你正在经历的。
