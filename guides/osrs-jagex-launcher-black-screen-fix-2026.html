Jagex Launcher Black Screen: Decision-Tree Fix (2026)

Updated August 19, 2026  |  15 min read  |  By Yanchun Wu

The Jagex Launcher opens to a black window, freezes before the game list appears, or kicks you back to the login screen in a loop. This guide is a verdict-first decision tree: answer one question at a time, run the matching step, and you will almost always be playing within ten minutes. Every step includes a copy-paste command.

📅 Updated: August 2026 — Troubleshooting · 14 min read
🛡️ Level: All
🆕 NEW

A black Jagex Launcher screen is rarely a graphics-card problem and almost never a RuneScape server problem. In 2026 the usual causes are a corrupted local cache, a launcher update that half-installed, a permissions or antivirus block, or a display/compatibility mismatch on Windows. Start with the RuneLite setup guide if you only use the standalone client, and if your phone shows a black screen instead, jump to the Android black screen fix — this page is for the desktop Jagex Launcher.

The decision tree below is designed so you do the cheapest, safest fixes first. Do not skip to the reinstall until you have tried cache clearing and "run as administrator" — those two steps alone fix roughly two out of three black-screen cases reported on the official client. Keep this tab open while you work; each branch links to the detailed section lower on the page.

💡 Quick Verdict (read this first)

If the launcher shows a black or blank window: kill every Jagex process, delete the Launcher cache folder, then relaunch as Administrator. That single sequence fixes the majority of 2026 black-screen reports. If it still loops at login, the problem is credentials or a network/antivirus block, not your GPU. If it still will not draw a window at all, use compatibility mode, then a clean reinstall as the last resort.

1. 🔍 What a Black Screen Actually Means

Before fixing anything, identify which "black screen" you have. They are different failures and the fix differs. Match your symptom, then follow the tree.

① Blank window, no game list (launcher renders nothing)

The launcher process starts, a window appears, but it is solid black or white with no buttons, no Jagex logo, and no account list. This is almost always a local rendering or cache fault: a half-written UI file, a corrupted WebView/Electron resource, or a GPU/driver hand-off that fails. Network status does not matter here — the window never tried to talk to a server.

② Launcher opens fine, but OSRS itself is black

You can pick your account and the game launches, but the RuneScape client window is black while the launcher is fine. That is a client-side graphics fault (GPU plugin, 117HD, or a bad driver), not a launcher fault. Treat it as a lag/FPS issue and see the dedicated lag and FPS drop guide rather than reinstalling the launcher.

③ Login loop: enter details, get kicked back to login

The launcher renders perfectly, you type your email and password (or it accepts a saved session), and then it snaps back to the login screen with no error or with a vague "something went wrong." This is not a display fault. It points to credential/token trouble, a blocked connection to the auth servers, an over-aggressive antivirus, or a clock/time mismatch on your PC.

④ Launcher never appears, only a flash in the taskbar

You double-click, the icon flickers in the taskbar for a second, and nothing opens. The process likely crashes on startup — common after a failed update, a corrupted install, or missing Visual C++ runtimes. This is the case where compatibility mode and a reinstall earn their place.

💡 One Quick Test Before Anything Else

Press Ctrl + Shift + Esc, open the Details tab, and look for JagexLauncher.exe (and any RuneScape.exe). If the process is there but you see no window, it is a rendering fault (go to cache + compat). If the process disappears within two seconds, it is crashing on launch (go to reset + reinstall). This single observation cuts your diagnosis time in half.

Answer each question top to bottom. The first "yes" branch tells you which detailed step to run. Most people resolve at branch A or B.

① The 5 questions

🧭 Follow the First Match

Q1. Does the JagexLauncher.exe process stay alive in Task Manager but show no window?
→ Yes: Go to Step 1 (cache), then Step 3 (compatibility). (Branch A — rendering fault)

Q2. Does the launcher crash within ~2 seconds (process vanishes)?
→ Yes: Go to Step 4 (reset), then Step 5 (reinstall). (Branch B — broken install)

Q3. Does the launcher render, but you loop back to login?
→ Yes: This is auth/network, not display. Clear cache anyway, then check antivirus, clock, and run as admin. See Step 2 and the FAQ on login loops. (Branch C)

Q4. Did this start right after a Windows update or GPU driver update?
→ Yes: Go to Step 3 (compatibility + driver rollback).

Q5. Is your antivirus or corporate firewall brand new or did it just update?
→ Yes: Add exclusions for the Jagex folders (paths in Step 2) before reinstalling.

② Visual map of the tree

③ What NOT to do first

  • Do not immediately reinstall Windows. The launcher is a self-contained app; a full OS reset is massive overkill.
  • Do not edit the registry hunting for Jagex keys unless a later step explicitly says so. The fix lives in %LOCALAPPDATA%, not in system hives.
  • Do not disable your firewall entirely. Add a folder exclusion instead (Step 2). A blanket disable exposes the rest of your PC.
  • Do not assume it is the servers. A launcher that will not draw a window cannot even reach a server. Check home network troubleshooting only for login-loop cases.

3. 🧹 Step 1 — Clear Launcher & Game Cache

This is the single highest-success fix. The Jagex Launcher caches its UI and update state locally; when that cache is half-written (usually from a killed update or a disk hiccup) the window renders black. Clearing it forces a clean redownload on next launch.

① Kill all Jagex processes first

Never delete cache files while the launcher is running — Windows will lock them. Close everything, then run this from a normal Command Prompt:

🖥️ Command Prompt

taskkill /f /im JagexLauncher.exe
taskkill /f /im RuneScape.exe
taskkill /f /im RuneLite.exe

You should see "SUCCESS" or "not found" for each. "Not found" is fine — it just means that process was not running.

② Delete the Launcher cache folder

The launcher stores its UI and update files here. Deleting the folder is safe — it is recreated on next launch:

🗑️ One-line cache wipe (Windows)

rd /s /q "%LOCALAPPDATA%\Jagex\Launcher"

To also clear the OSRS client cache (recommended if the game window itself was black):

rd /s /q "%LOCALAPPDATA%\RuneScape"

And the legacy client cache if present:

rd /s /q "%LOCALAPPDATA%\jagex"

If you prefer a GUI, open File Explorer, paste %LOCALAPPDATA%\Jagex into the address bar, and delete the Launcher folder. Then paste %LOCALAPPDATA% and delete RuneScape if it exists. Emptying these does not delete your account, your settings sync to the cloud, and your bank is server-side.

③ Relaunch and watch the download

Start the launcher normally. The first launch after a cache wipe will take longer — you will see a progress bar as it redownloads the UI bundle. If the black screen is gone, stop here. If it returns, the cache was a symptom, not the cause, and you move to Step 2.

⚠️ Cache Keeps Coming Back?

If you clear the cache, it works once, then the black screen returns after the next auto-update, your disk may be failing or your antivirus is silently quarantining launcher files. Run chkdsk /f (needs a reboot) and add the Jagex folders to your antivirus allow-list before blaming the launcher.

4. ⚙️ Step 2 — Run as Administrator & Fix Permissions

The Jagex Launcher writes to protected program folders during updates. If its normal-user token cannot write there, an update half-installs, and the next launch is a black screen. Running as Administrator, or fixing the folder permissions, resolves this cleanly.

① Run as Administrator (quick test)

Right-click the Jagex Launcher shortcut or JagexLauncher.exe and choose Run as administrator. If the black screen disappears, you have found it: the launcher needs elevated write access. To make it permanent:

🔒 Make "Run as admin" permanent

Right-click JagexLauncher.exe → Properties → Compatibility tab → tick "Run this program as an administrator" → Apply → OK.

Typical install path:

C:\Users\<YourName>\AppData\Local\Jagex\Launcher\JagexLauncher.exe

② Fix folder ownership (when admin alone is not enough)

On some corporate or shared PCs the Jagex folder is owned by a different account. Re-take ownership from an elevated Command Prompt:

🛠️ Reset permissions (elevated CMD)

takeown /f "%LOCALAPPDATA%\Jagex" /r /d y
icacls "%LOCALAPPDATA%\Jagex" /grant "%USERNAME%":(F) /t

This gives your account full control of the Jagex folder tree. Reboot once, then launch normally (you can untick the admin box after this if you want).

③ Add antivirus / firewall exclusions

Several 2026 black-screen reports trace to antivirus silently blocking the launcher's updater. Add these folders to your scanner's allow-list (Windows Defender shown; other vendors have equivalent "exclusions" pages):

🛡️ Windows Defender exclusion (PowerShell, admin)

Add-MpPreference -ExclusionPath "$env:LOCALAPPDATA\Jagex"
Add-MpPreference -ExclusionPath "$env:LOCALAPPDATA\RuneScape"
Add-MpPreference -ExclusionProcess "JagexLauncher.exe"

If you use a third-party suite (Norton, McAfee, Bitdefender, Avast), open it and exclude the same two folders and the executable. This is especially important for login-loop cases, where the scanner blocks the auth handshake rather than the drawing.

④ Check your system clock

A wrong clock breaks TLS certificate checks, and the launcher will bounce you to login with no clear error. Sync it:

⏰ Sync time (CMD, admin)

w32tm /resync

Or Settings → Time & Language → Date & Time → "Sync now." Also enable "Set time automatically."

5. 🪟 Step 3 — Compatibility & Display Settings

If the process stays alive but the window is black, the launcher's embedded browser surface is failing to initialize on your GPU or display. Compatibility mode and a few display tweaks usually force it to fall back to a working renderer.

① Compatibility mode + disable fullscreen optimizations

🪟 Properties checklist

Right-click JagexLauncher.exe → Properties → Compatibility:

  • Tick "Run this program in compatibility mode for:" → choose Windows 8.
  • Tick "Disable fullscreen optimizations."
  • Tick "Override high DPI scaling behavior" → set to Application.
  • Apply → OK, then relaunch.

② GPU driver: update or roll back

A black launcher window right after a driver update is a classic GPU hand-off failure. Either update to the newest studio/driver, or roll back if the newest one broke it:

🔄 Roll back a bad driver (Device Manager)

Win + X → Device Manager → Display adapters → right-click your GPU → Properties → Driver tab → "Roll Back Driver" (greyed out means none available; then use "Update Driver" → auto-search instead).

For NVIDIA, prefer the Studio Driver over Game Ready for a launcher/UI app — it is validated for UI frameworks. For integrated Intel graphics, make sure you are not on a 2019-era driver; the embedded renderer the launcher uses improved a lot after 2021.

③ Force software rendering as a test

If you suspect the GPU path entirely, you can force the launcher's UI to use the CPU. This is slower but proves the point:

🧪 Test with software GL (CMD)

set JAGEX_LAUNCHER_GL=swiftshader
start "" "%LOCALAPPDATA%\Jagex\Launcher\JagexLauncher.exe"

If the window now draws, your GPU/driver is the culprit — keep the variable or fix the driver. Remove it with set JAGEX_LAUNCHER_GL= when done testing.

④ Multiple monitors / HDR / 4K scaling

Launcher black screens spike on setups with mixed DPI monitors or HDR enabled. Quick things to try:

  • Move the launcher to your primary 1080p/1440p monitor and launch there.
  • Temporarily turn HDR off (Settings → System → Display).
  • Set scaling to 100% on the monitor you launch from.
  • If you use a 4K TV as a monitor, switch it to "PC" mode or 60 Hz temporarily.

6. ♻️ Step 4 — Reset / Repair the Launcher

When the install is broken but you do not want a full reinstall yet, Windows can repair it in place. This re-registers the app and replaces corrupt system pieces without touching your cache (which you already cleared in Step 1).

① Repair via Windows Apps settings

🔧 Repair (keeps your data)

Settings → Apps → Installed apps → search Jagex Launcher → ⋮ → Advanced options → Repair. If "Repair" is missing, use Reset (Reset clears local app data but not your account).

"Repair" is safe and keeps everything. "Reset" wipes the launcher's local app-data but your account and settings live in the cloud, so you just sign in again. Prefer Repair; use Reset only if Repair is unavailable or did not help.

② Re-register the app package (PowerShell)

If the entry is corrupted so badly that Settings cannot open it, re-register from an elevated PowerShell:

📦 Re-register (admin PowerShell)

Get-AppxPackage *Jagex* | ForEach-Object { Add-AppxPackage -DisableDevelopmentMode -Register "$($_.InstallLocation)\AppXManifest.xml" }

If that returns nothing, the launcher is installed as a normal EXE (not a Store app) — skip to Step 5 reinstall.

③ Repair Visual C++ runtimes

The launcher depends on Visual C++ redistributables. A missing or corrupt one causes a 2-second crash (Branch B). Reinstall the latest supported runtimes:

  • Download "Visual C++ Redistributable for Visual Studio 2015–2022" (x64) from Microsoft.
  • Run it; choose Repair if offered, otherwise Install.
  • Reboot, then try the launcher again.

Also confirm .NET Desktop Runtime 6/8 is present — the launcher's UI framework needs it. Windows Update usually provides it, but a paused update can leave it missing.

7. 💻 Step 5 — Clean Reinstall (Nuclear Option)

Only here if Steps 1–4 failed. A clean reinstall removes the broken install and every leftover file, then lays down a fresh copy. Done properly, this fixes essentially all remaining black-screen cases.

① Uninstall completely

🧨 Uninstall (Settings)

Settings → Apps → search Jagex Launcher → Uninstall. Confirm. Also uninstall RuneScape and RuneLite if listed.

② Delete every leftover folder

Uninstallers leave cache behind on purpose (to save your settings). For a true clean slate, delete these after uninstalling:

🗑️ Remove leftovers (CMD)

rd /s /q "%LOCALAPPDATA%\Jagex"
rd /s /q "%LOCALAPPDATA%\RuneScape"
rd /s /q "%LOCALAPPDATA%\RuneLite"
rd /s /q "%APPDATA%\Jagex"
rd /s /q "%PROGRAMFILES%\Jagex"

③ Reinstall from the official source only

Download a fresh installer directly from jagex.com/launcher. Do not use a cached installer you found in Downloads, and never run a "launcher fix" EXE from a forum or video link — those are the most common malware vectors for OSRS accounts.

⬇️ Clean install flow

1) Visit jagex.com/launcher in your browser.
2) Download the Windows installer.
3) Right-click it → Run as administrator (this sets correct permissions from the start).
4) Launch the freshly installed launcher normally; sign in.

④ If it STILL black-screens after a clean reinstall

At this point the launcher is innocent — the fault is environmental. Check, in order:

  • Another user account: create a new Windows user, sign in there, install the launcher. If it works, your main profile is corrupt — migrate to the new one.
  • Clean boot: msconfig → Selective startup, disable all non-Microsoft services, reboot, try launcher. If it works, a background app (overlay, RGB software, VPN) is interfering.
  • Different GPU: on a laptop with both Intel + NVIDIA, force the launcher to the integrated GPU in Windows Graphics Settings, or vice versa.
  • OS corruption: sfc /scannow then DISM /Online /Cleanup-Image /RestoreHealth from an elevated prompt.

If even a clean-boot, new-user, fresh-Windows test fails, the issue is hardware (failing GPU or RAM). Run a memory test (Windows Memory Diagnostic) and a GPU stress test. That is outside launcher scope — but it is the honest end of the tree.

8. ❓ Frequently Asked Questions

Will clearing the cache delete my account, bank, or progress?

No. Your account, bank, skills, and settings are stored on Jagex's servers and synced to your login. The local cache only holds downloaded UI files and the offline game assets. Clearing it forces a redownload; you simply sign back in. This is the safest first step and there is no risk to your account.

Why does the launcher loop back to login with no error?

A login loop with a perfectly drawn launcher is almost never a display fault. The usual causes are: an antivirus blocking the auth handshake, a wrong system clock breaking certificate checks, a cached corrupt session token, or a blocked connection to the auth servers. Clear the cache, sync your clock (w32tm /resync), add antivirus exclusions, then try. See our can't-login guide for the account-side checks too.

Is the black screen caused by the RuneScape servers being down?

Almost never. A launcher that will not draw a window cannot reach a server at all — the fault is local. Server issues show up as error messages, queue screens, or disconnects after you are already in game, not as a black launcher window. Only investigate the network for login-loop cases; otherwise the fix is on your PC.

Do I need to reinstall Windows to fix this?

No. Reinstalling Windows is massive overkill. The decision tree resolves the overwhelming majority of cases at cache-clear, run-as-admin, or compatibility mode. A full clean reinstall of just the launcher (Step 5) is the "nuclear" end — and even that rarely requires touching Windows itself.

My antivirus quarantined JagexLauncher.exe. What now?

Restore the file from quarantine and add the Jagex folders to the scanner's exclusions (paths in Step 2). Then reinstall the launcher once so the restored file is replaced by a clean, properly-signed copy. Do not just keep running a quarantined-then-restored file — it may be incomplete. The official installer is digitally signed by Jagex; if your scanner still flags a fresh download, verify you got it from jagex.com/launcher.

The fix worked once, but the black screen returns after every update. Why?

That pattern points to your disk or antivirus. An auto-update writes a new UI bundle; if your AV quarantines part of it, or your disk has bad sectors, the next launch is black again. Run chkdsk /f, add AV exclusions, and check the drive's health (CrystalDiskInfo or wmic diskdrive get status). If the drive reports "Caution" or "Bad," back up and replace it before chasing the launcher further.

Does this guide apply to the Mac or Linux launcher?

The decision tree logic is the same (cache first, permissions second, reinstall last), but the paths and commands differ. On Linux the native client and RuneLite are covered in our Linux client freeze fix. On Mac, clear ~/Library/Application Support/Jagex and reinstall from the official DMG; Gatekeeper permission errors are the Mac equivalent of the Windows admin step.

Can I just use RuneLite and skip the Jagex Launcher?

Jagex Launcher is now required to launch the official client and RuneLite on desktop — you generally cannot skip it. If the launcher itself will not open but you have RuneLite installed separately, the RuneLite setup guide covers getting RuneLite running, but you will still need a working launcher for the official client. Fix the launcher with this tree; it is the same fix either way.

Compatibility mode for Windows 8 worked — should I leave it on?

Yes, leaving it on is harmless and is a legit permanent fix for GPU hand-off issues. Many players run the launcher in Windows 8 compatibility mode indefinitely with zero downside. The only reason to remove it is if a future launcher update specifically asks you to, which is rare.

I see a black screen only on my second monitor. What gives?

Mixed-DPI or HDR secondary monitors often break the launcher's embedded UI renderer. Launch on your primary 1080p/1440p monitor, turn HDR off, set scaling to 100%, and enable "Override high DPI scaling → Application" in the compatibility tab (Step 3). Once it draws, you can usually move it to the other monitor afterward. This is a display-config issue, not a launcher bug.
