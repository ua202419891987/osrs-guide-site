1. Why RuneLite Drops FPS (The Real Cause)

RuneLite renders Old School RuneScape on your machine instead of Jagex's lightweight official client. That's great for HD plugins and overlays — but it means your hardware and your settings directly control frame rate. When FPS drops, it's almost always one of these four things:

🎯 The Four FPS Killers

  • GPU renderer misconfigured — RuneLite's built-in GPU plugin offloads rendering to your graphics card. Bad settings (or a broken driver) tank it.
  • Not enough RAM allocated — RuneLite ships with a small Java heap. Run 20+ plugins and it starts garbage-collecting constantly → stutter.
  • Heavy plugins — 118 HD, GPU, Ground Items, Entity Hider, and big overlays each cost frames.
  • OS-level power / vsync issues — Windows "power saver" or forced vsync can cap or destabilize FPS.

It is very rarely your internet. OSRS sends tiny packets; network lag shows as delayed hits or chat, not low FPS. If your frame counter (top-left, enable it in Settings → General → Show FPS) dips below 30 in quiet areas, it's local — read on.

💡 Enable the FPS Counter First

Before changing anything, turn on Settings → General → Show FPS. You need a number to know if a change helped. Target a stable 50 FPS (OSRS is capped at 50 ticks/frames per second on the game logic side, though the client can render higher).

2. Step 1: Update Everything First

Most "sudden" FPS drops appear right after a game update or a GPU driver change. Rule these out before touching settings:

② 🔄 Update RuneLite Itself

RuneLite auto-updates, but a stuck process can miss it. Fully close RuneLite (right-click tray icon → Exit), then relaunch. If it won't update, download a fresh copy from runelite.net.

③ 📟 Update Your GPU Driver

⚠️ Did FPS Drop After a Driver Update?

Sometimes a new driver regresses OpenGL. If the drop started the day you updated, roll back via Device Manager (Windows) or use an older Adrenalin version. Check the RuneLite Discord — the community usually pins known-bad driver versions within hours.

④ ☕ Update Java (Windows)

RuneLite bundles its own Java, so this is usually automatic. If you use a custom launcher, ensure you're on a recent 64-bit Java 17+. 32-bit Java caps memory and is slower.

🛠️ The "Instant 10-FPS" Change

If you only change one thing: set Texture Scaling back to 1.0 and set FPS Target to 50. Players routinely recover 10-15 FPS just from these two. Texture scaling above 1.0 is the most common "I don't know why my FPS is bad" setting.

⑤ Should You Use 118 HD?

The 118 HD plugin adds shadows, dynamic lighting, and PBR textures. It looks amazing but roughly doubles GPU load. If you're on an integrated GPU (Intel/Apple base models), 118 HD is the first thing to disable when FPS drops. On a dedicated GPU it's usually fine at FPS Target 50.

💡 Quick Toggle

Keep the GPU plugin enabled but pin 118 HD / HD plugins to a keybind or the plugin's "disable in combat" option so you get pretty visuals while skilling and max performance while bossing.

4. Step 3: Give RuneLite More RAM (-Xmx)

RuneLite's Java process defaults to a small heap (around 512 MB). Every plugin, every overlay, every cached sprite lives there. Run 20+ plugins (Ground Items, Entity Hider, Tilemarkers, HD, etc.) and the JVM starts constant garbage collection → micro-stutter even when FPS looks okay.

⑥ How to Increase the Heap

Windows (RuneLite launcher)

Right-click the RuneLite desktop shortcut → Properties. In the Target field, append a JVM flag. If Target ends with Runelite.exe, change it to include:

-Xmx1024m (for 1 GB) or -Xmx2048m (for 2 GB). Example: "C:\Program Files\RuneLite\RuneLite.exe" -Xmx1024m

Manual Java launch (any OS)

If you launch via java -jar, run:
java -Xmx1024m -jar RuneLite.jar

Plugin loadoutRecommended -Xmx
Light (5-10 plugins)512-768 MB (default OK)
Medium (10-20 plugins)1024 MB
Heavy (20+ plugins, HD, overlays)1536-2048 MB
⚠️ Don't Over-Allocate

Setting -Xmx4096m on a machine with 8 GB RAM leaves the OS starved and can cause more stutter from OS swapping. Match the value to your total RAM: on 8 GB, cap at 2048m; on 16 GB+, 2048-3072m is safe.

5. Step 4: Windows & macOS Graphics Tweaks

⑦ Windows: Power & GPU Preference

Set Power Plan to High Performance

Control Panel → Power Options → High performance. "Balanced" throttles your CPU/GPU under load and is a classic laptop FPS killer.

Force Your Dedicated GPU (laptops with 2 GPUs)

Windows Settings → System → Display → Graphics. Add RuneLite.exe and set it to High performance so Windows doesn't run it on the weak integrated GPU.

Disable Full-Screen Optimizations

Right-click RuneLite.exe → Properties → Compatibility → check "Disable fullscreen optimizations". Reduces stutter in borderless window mode.

⑧ macOS: Retina & Metal

🍎 The Retina Scaling Trap

On a Retina Mac, RuneLite can render at 2x the logical resolution. If FPS is low, go to RuneLite → Settings → GPU → UI scaling and set it to 1.0, or run the client at "default" resolution instead of "more space". Apple Silicon (M1/M2/M3) handles OSRS very well; Intel Macs benefit most from this tweak.

Also ensure macOS is updated — Metal backend fixes for RuneLite/GPU ship in point releases.

6. Step 5: Find the Laggy Plugin

If FPS is fine until you enable a specific plugin, isolate it. The usual suspects, ranked by FPS cost:

⑨ The Fast Isolation Method

  1. Open Settings → Plugins and note what's on.
  2. Disable everything except GPU. Check FPS — should be high.
  3. Re-enable plugins one at a time; watch the FPS counter.
  4. The plugin that drops you 10+ FPS is your culprit — keep it off, or accept the cost.
💡 Ground Items Tip

Instead of highlighting "all items", use specific filters (e.g., only >50k value). A short highlight list costs far less than "show everything in a busy raid."

7. How to Tell: GPU, CPU, or Network?

Not every "lag" is FPS. Diagnose correctly so you fix the right thing:

🔍 Symptom → Cause

  • Frame counter low (<30) even standing still → Local GPU/CPU. Apply this guide.
  • FPS fine, but attacks/hits delayed → Network latency. Check your ping to the OSRS world (in-game 🌐 icon). Not a client issue.
  • FPS drops only in busy areas (GE, raids) → Plugin/entity load. Use Section 6.
  • FPS drops only during big explosions/lighting → GPU lighting. Turn off Lighting / 118 HD.
  • Random stutter every few seconds → RAM garbage collection. Apply -Xmx (Section 4).

If after all this FPS is still bad on a modern dedicated GPU, it may simply be time — OSRS's OpenGL path is CPU-light but the GPU plugin's overhead grows with plugin count. Trim plugins and you'll be back to a smooth 50.

8. Advanced: Config Tweaks & When to Upgrade Hardware

Once the basics are done, two deeper levers remain: RuneLite's saved configuration and your actual hardware. This section is for players who fixed the obvious settings but still aren't happy with the numbers.

① The RuneLite Settings File

Every toggle you flip is saved to RuneLite's configuration, not the game servers. On Windows this lives in %USERPROFILE%\.runelite\settings.properties (the runelite folder next to your profile). If a setting "won't stick" after a restart, it's usually because RuneLite is running from a second installation, or a corrupted line in that file is overriding the UI. You can safely close RuneLite, open the file in Notepad, and delete the single offending line — it regenerates on the next launch. Power users also edit this file directly to enable flags the GUI hides, but for FPS the in-client GPU panel is enough 99% of the time.

② OpenGL vs the Vulkan Backend

Modern RuneLite offers two hardware paths under Settings → GPU: the classic OpenGL backend (stable, works everywhere) and a newer Vulkan backend (lower CPU overhead on some systems). If OpenGL stutters on your machine but your GPU is modern, switch to Vulkan and reboot RuneLite — several players report a 10–20% smoothness gain on AMD and integrated Intel graphics. Conversely, if Vulkan causes flicker or crashes, fall back to OpenGL. There is no universal winner; test both with the FPS counter open.

③ Low-Detail & Idle-Animation Options

Two underused toggles cut GPU work dramatically:

  • Low Detail mode (Settings → Graphics): removes rooftops, simplifies scenery, and drops far-plane detail. In busy areas this alone can recover 10+ FPS.
  • Disable idle animations / ground decorations: idle player animations and decorative ground tiles are redrawn every frame. Turning them off helps in crowded spots like the GE or Chambers of Xeric.

Neither hurts gameplay — they only reduce eye candy you probably weren't watching anyway, and the FPS return is real.

④ Multi-Monitor & Mixed-DPI Fixes

If RuneLite lives on a second monitor or a high-DPI laptop screen, render load scales with pixel count, not logical size. A 4K secondary monitor renders four times the pixels of 1080p for the same "window size." Fixes:

  • Drag RuneLite to your primary, lower-DPI monitor for bossing.
  • In Settings → GPU → UI scaling, set scaling to 1.0 and let the OS handle DPI rather than double-scaling the canvas.
  • Avoid "extend these displays" with mismatched refresh rates; a 60 Hz + 144 Hz combo can force vsync-like stutter on the client.

⑤ When It's Actually Your Hardware

If every setting is optimal and FPS is still poor, the bottleneck is physical. OSRS's logic is CPU-light and single-threaded, but the GPU plugin is genuinely GPU-bound, and Java's heap is RAM-bound. Use this table to decide what to spend on:

SymptomLikely bottleneckUpgrade that helps
Low FPS everywhere, even empty areasWeak integrated GPUAny dedicated GPU (GTX 1650+)
Stutter every few secondsToo little RAM / 8 GB systemAdd RAM to 16 GB + -Xmx2048m
Fine solo, dies in raids / GEEntity / plugin loadDedicated GPU + trim plugins
Good FPS but high temperaturesThermal throttlingCooling pad / repaste

For most players a modest dedicated GPU (even a used GTX 1060 or 1650) transforms the experience, because the GPU plugin's fragment work scales directly with render resolution — more cores and bandwidth means more headroom before you hit 50 FPS.

⑥ Thermal Throttling on Laptops

Laptops silently cut clock speed when hot, which looks exactly like a settings problem. If FPS drops after 10–15 minutes of play but is fine on a cold launch, that's throttling. Mitigations: use a laptop stand or cooling pad for airflow, clean dust from vents, and consider limiting FPS Target to 50 so the machine isn't rendering flat-out. A $20 cooling pad often recovers more sustained FPS than any in-client tweak, because it attacks the real cause instead of the symptom.

💡 The Takeaway

Settings fix 80% of cases, the config file and backend choice fix another 10%, and real hardware solves the last 10%. Work the list top to bottom before buying anything — most "my laptop can't run OSRS" complaints are solved at the Texture Scaling slider, not the store.

⑦ Complaints That Aren't Really FPS (And Their Real Fix)

Several issues get mislabeled as "low FPS" but have completely different causes — chasing client settings won't help them, and knowing the difference saves hours of pointless tuning:

  • World-hop stutter: a brief frame drop right after hopping worlds is server-side area loading, not your GPU. It settles within 2–3 seconds and needs no setting change. If the dip happens only on hops and nowhere else, your client is healthy.
  • Official client "feels smoother": the official client caps at 30 FPS and uses Jagex's purpose-built renderer, while RuneLite at 50 FPS shows more frames and exposes minor pacing inconsistencies. If the game feels uneven rather than slow, lock FPS Target to a steady value your machine actually holds instead of letting it spike and dip.
  • Sudden regression after a game update: RuneLite occasionally resets plugin configurations on major releases. If FPS craters the day after an update, open Settings → GPU and confirm 118 HD / Lighting didn't get silently re-enabled — that single toggle explains most "it was fine yesterday" reports.
  • Background apps stealing GPU: browsers with hardware-accelerated video, Discord overlays, and screen recorders all borrow GPU time from RuneLite. Close them or disable hardware acceleration while bossing; the freed headroom is often larger than any in-client tweak.
  • Settings vanished after reinstall: switching PCs or reinstalling can drop your tuned config if it wasn't backed up. Link RuneLite to a RuneLite account (Settings → Account) so your GPU and plugin settings sync and survive a reinstall.

⑧ Back Up and Verify Your Tuning

Two habits stop you from repeating this whole process from scratch:

  • Back up the settings file (settings.properties) to a cloud drive after you've tuned everything. A two-second copy restores your exact config on any machine, including the -Xmx flag and every plugin toggle.
  • Log a before/after: note your FPS in a quiet area (the Grand Exchange bank) and in a busy one (a popular world's GE) before and after each change. Numbers beat guesswork — if a change didn't move the counter, revert it instead of stacking tweaks that fight each other.
  • Use a benchmark world: a high-population free-to-play world piles hundreds of players, pets, and ground items into one screen, making it the harshest realistic stress test. If you hold 50 FPS there with 118 HD off, you'll hold it anywhere. Treat it as your go-to "did my change actually work?" check before declaring victory, rather than judging from a quiet bank.

The underlying rule is consistency: a config that holds a steady 50 in every area beats a fragile one that hits 60 in town and 20 in a raid. Tune for the worst case, not the best, and you'll never white-screen mid-Zulrah again. Most "RuneLite runs badly on my PC" stories end at the Texture Scaling slider or a forgotten HD toggle — work the list in order, measure each step, and the game will feel smooth on hardware far more modest than you'd expect.

9. RuneLite FPS FAQs

Why is my FPS fine at home but terrible in the Grand Exchange?

That's almost always plugin/entity load. The GE has hundreds of players, pets, and ground items. Disable or filter Ground Items and Entity Hider there, or use "disable HD in crowded areas" if your plugin supports it.

Is 50 FPS the max in OSRS?

The game logic runs at 50 ticks/second, so anything above ~50 FPS is the client rendering duplicate frames. Setting FPS Target to 50 is ideal — higher just wastes GPU and battery.

My FPS dropped right after a game update. What happened?

Either RuneLite needs its own update (restart it), or a new driver regressed OpenGL. Restart RuneLite first; if that doesn't help, check the RuneLite Discord for a known-bad driver version to roll back.

Does -Xmx actually help FPS or just stop crashes?

Both. Insufficient heap causes constant garbage collection, which shows as periodic stutter even when the FPS counter looks okay. Bumping to 1024-2048 MB smooths that out.

Should I turn GPU off if my laptop has only integrated graphics?

Integrated GPUs (Intel UHD, Apple base M-chips without Pro/Max) often do better with GPU on but 118 HD and Lighting off. Test both — but never run 118 HD on integrated graphics.

Texture scaling above 1.0 — is it ever worth it?

Only on a strong dedicated GPU where you have FPS to spare and want crisper textures. For most players it's pure cost with little visual gain. Keep it at 1.0 (Nearest).

Why does RuneLite feel smooth on one monitor but stutters on my second?

Running the client across different refresh rates or on a high-DPI secondary monitor increases render load. Keep RuneLite on your primary, high-refresh monitor and match UI scaling to it.

I have a great GPU but still low FPS — what gives?

Check Windows isn't forcing the integrated GPU (Section 5), power plan is High Performance, and RuneLite has enough RAM. A strong GPU paired with a throttled CPU or tiny heap still stutters.

Will these settings help the mobile app too?

No — the mobile app is a separate renderer. For mobile, lower the in-game graphics settings and close background apps. This guide is for the desktop Rune Lite client.

Is there a one-click "performance mode" in RuneLite?

Not officially, but the GPU plugin's defaults plus FPS Target 50 and Texture Scaling 1.0 get you 90% of the way. Combine with the plugin isolation method in Section 6 to finish the job.
